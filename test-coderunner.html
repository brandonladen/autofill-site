CodeRunner test page

A Moodle-shaped quiz running CodeRunner's real editor code (ui_ace.js and ui_ace_gapfiller.js from the qtype_coderunner repository) behind a small stand-in for Moodle's module loader. Each question is started by the same inline script Moodle prints, amd.newUiWrapper("<ui>", "<textarea id>"). Q2's dataset lives only in the editor's starter code; Q3 is a gap-filler (only the gaps are editable); Q4 uses the Scratchpad UI layout (JSON answer). "Check" shows exactly what Moodle receives. The variant token defeats the answer caches.
