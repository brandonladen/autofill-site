CodeRunner test page

A Moodle-shaped quiz with two CodeRunner questions using a real Ace editor wired the way CodeRunner's ui_ace.js does it: the answer textarea is hidden, the editor copies its content into the textarea on every change, and the form submits the textarea. Question 2 keeps its dataset only in the editor's starter code (like the OUK CSA 821 exam), so a correct answer must use that data. "Check" shows exactly what Moodle would receive. The variant token defeats the answer caches.
